Révisions BTS SIO

Un site de révision interactif pour les deux années de BTS SIO : fiches par matière, quiz de 629 questions et un Code Lab pour tester du code directement dans le navigateur. Je l'ai conçu pour réviser, et je le partage avec ma classe.

En bref

Le site regroupe les fiches de 1re année et les cours de 2e année dans une seule interface, utilisable sur ordinateur comme sur téléphone. Le contenu vient des supports de cours : les fiches sont courtes pour relire vite, et le quiz permet de vérifier ce qu'on a retenu.

Le site est publié avec GitHub Pages à partir d'un dépôt GitHub. Il ne demande aucune installation : il suffit d'ouvrir le lien dans un navigateur.

Le site évolue : les fiches de 2e année sont ajoutées au fur et à mesure que les cours sont disponibles. Le tableau de bord indique ce qui est déjà en ligne.

Ce que fait le site

Fiches par matière

14 modules pour la 1re année (systèmes, réseau, RGPD, cybersécurité, algorithmique, PHP, Java, MCD, SQL, maths, anglais, culture générale et CEJM avec 11 chapitres). En 2e année, des fiches sur le CEJM, le CGE, les maths, le SQL, Java et la cryptographie.

Quiz interactif

629 questions, en QCM ou à saisir. Filtres par année, matière (19 matières) et type, avec le score et la progression.

Code Lab

Un éditeur avec plusieurs fichiers (Python, PHP, Java), coloration syntaxique, numéros de ligne, annuler et rétablir. Il propose 10 exercices guidés, un terminal et le téléchargement du fichier actif.

Sauvegarde locale

Les brouillons sont conservés dans le navigateur, et une alerte apparaît avant de fermer une page qui contient des modifications non enregistrées.

Thème et mobile

Une interface inspirée d'un terminal (vert sur fond sombre). La mise en page s'adapte aux téléphones, sans défilement horizontal.

Captures d'écran

Captures prises sur le site en ligne, sur ordinateur.

Organisation du site

Le dépôt est organisé en trois parties : les pages de premier niveau, un dossier par année, et un dossier assets/ pour le style, les scripts et les images. 

Revision-BTS-SIO/
├── index.html          tableau de bord
├── quiz.html           quiz général
├── code-lab.html       éditeur et exercices (Python, PHP, Java)
├── premiere/           fiches de 1re année
│   └── cejm/           11 chapitres de CEJM
├── deuxieme/           fiches de 2e année
│   └── cejm/           chapitres de CEJM (droit et management)
└── assets/
    ├── css/            styles et thème terminal
    ├── js/             navigation, quiz, Code Lab et banques de questions
    └── img/            images des fiches
Pourquoi cette organisation : les questions du quiz sont réparties dans plusieurs fichiers JavaScript. Chaque matière est ainsi plus facile à corriger ou à compléter, sans toucher au reste du site.

Comment c'est fait

  • Pas de framework : ce sont des fichiers HTML, CSS et JavaScript publiés tels quels, sans étape de compilation.
  • Python dans le navigateur avec Pyodide. Le code tourne dans un Web Worker, pour que l'interface ne se bloque pas, et l'exécution s'arrête automatiquement au bout de 10 secondes.
  • PHP et Java sont envoyés à Judge0 CE, un service qui exécute le code dans un environnement isolé, puis renvoie le résultat.
  • Sauvegarde : les brouillons restent dans le localStorage du navigateur, donc sur l'appareil utilisé.
Connexion : l'éditeur, les fichiers, les exercices et la sauvegarde fonctionnent hors ligne une fois la page chargée. Internet est nécessaire pour charger Python et pour exécuter PHP et Java.

Ce que j'ai appris

  • Organiser un site statique qui grossit : une page par thème, des données séparées, des ajouts sans tout refaire.
  • Vérifier une page sur téléphone : tableaux, blocs de code et boutons doivent tenir dans l'écran.
  • Intégrer des outils externes (Pyodide, Judge0) et tenir compte de leurs limites : temps de chargement, connexion, délai d'exécution.
  • Mettre en ligne et documenter un projet : dépôt, README, captures et chiffres vérifiés sur le site.
